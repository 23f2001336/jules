# E-commerce Customer Retention Analysis – 2024

Author email (for verification): 23f2001336@ds.study.iitm.ac.in

This repository contains an LLM-assisted analysis of quarterly customer retention performance for an e-commerce business, compared against an industry benchmark.

## Data Overview

Customer Retention Rate – 2024 Quarterly Data:

- Q1: 70.65  
- Q2: 70.47  
- Q3: 70.68  
- Q4: 75.70  

Average (2024): 71.88  
Industry Target: 85  

The analysis code is in `analysis.py`, and the main visualization is saved as `retention_trend.png`.

---

## Key Findings

1. The average retention rate in 2024 is 71.88, which is 13.12 points below the industry target of 85.
2. Retention was flat across Q1–Q3.
3. Q4 shows an improvement to 75.70 but still falls below the target.

---

## Business Implications

- Reduced customer lifetime value (CLV).
- Increased dependency on new customer acquisition.
- Competitive disadvantage versus peers.

---

## Recommendations

The primary solution is to **implement targeted retention campaigns**:
- Focus on at-risk customers.
- Offer personalized incentives.
- Strengthen loyalty programs.
- Measure retention improvements quarterly.
